### How to use profile creation sites

- Complete every field: photo or logo, bio, business name, and contact details.
- Use the same business name, bio, and details on every profile.
- Add your website link in the profile's website field, where the platform allows it.
- Verify the profile where the platform offers verification.
- Start with high-authority, relevant sites before moving to smaller ones.
- Do not create duplicate or spammy profiles; one complete profile per site is enough.
- Update your profiles whenever your business details change.

## SEO Audit Checklist

Work through this checklist regularly to find and fix the issues holding a website back in search. It covers crawlability, technical SEO, on-page SEO, content, backlinks, local SEO, and tracking.

### 1. Crawlability and Indexation

- [ ] Check which pages search engines have indexed and which are missing.
- [ ] Fix crawl errors reported in Google Search Console.
- [ ] Submit and keep an XML sitemap up to date.
- [ ] Check robots.txt is not blocking important pages.
- [ ] Fix broken links and 404 errors.
- [ ] Fix redirect chains and redirect loops.
- [ ] Fix duplicate content and check canonical tags point to the right pages.

### 2. Technical SEO

- [ ] Improve page speed on mobile and desktop.
- [ ] Confirm the site is mobile-friendly.
- [ ] Confirm every page loads over HTTPS with no mixed content.
- [ ] Check Core Web Vitals and fix slow-loading pages.
- [ ] Add and validate structured data (schema) where it applies.
- [ ] Check that important pages are only a few clicks from the homepage.

### 3. On-Page SEO

- [ ] Every page has one unique, descriptive title tag.
- [ ] Every page has a unique meta description that matches the page.
- [ ] Headings follow a clear H1, H2, H3 structure.
- [ ] Target keywords appear naturally, including in the first 100 words.
- [ ] Images have descriptive alt text and are compressed.
- [ ] Internal links connect related pages with descriptive anchor text.
- [ ] URLs are short, clean, and descriptive.

### 4. Content

- [ ] Content matches the search intent behind its target keywords.
- [ ] Thin, outdated, or duplicate pages are improved, merged, or removed.
- [ ] Important pages are updated regularly with fresh information.
- [ ] Content is original, helpful, and written for readers first.

### 5. Off-Page SEO and Backlinks

- [ ] Audit the backlink profile for quality and relevance.
- [ ] Check anchor text is varied and natural.
- [ ] Identify and disavow spammy or toxic backlinks.
- [ ] Compare the backlink profile with competitors to find gaps.
- [ ] Build links from relevant, high-authority sites, including profile creation sites.

### 6. Local SEO

- [ ] The Google Business Profile is complete, accurate, and verified.
- [ ] Business name, address, and phone number are consistent everywhere online.
- [ ] Reviews are monitored and answered.
- [ ] Local citations and directory listings are accurate.

### 7. Analytics and Tracking

- [ ] Google Search Console and Google Analytics are connected and collecting data.
- [ ] Track rankings, organic traffic, and conversions over time.
- [ ] Set up goals or events for enquiries, calls, and form submissions.
- [ ] Review the audit results and repeat the checklist after fixes are made.
